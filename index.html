How & Where to Download Admit Cards & Check Exam Dates

Two different download systems operate in Bangladesh govt recruitments. Here is the exact walkthrough for each:

📱 System A: Teletalk Web & SMS Portal

Petrobangla & BCIC
  1. The SMS Notification (From 16222):
    When the exam date is fixed, Teletalk sends an automated SMS to your registered SIM:
    "Admit card for the post of Asst Manager (CSE) is ready. User ID: [XXXX], Password: [YYYY]. Download from bogmc.teletalk.com.bd"
  2. Downloading Admit Card:
    Go to bogmc.teletalk.com.bd (for Petrobangla) or bcic.teletalk.com.bd (for BCIC). Click on the top "Admit Card" tab, input your User ID & Password, and click Submit.
  3. Printing Specs:
    Print 2 color copies on 80 GSM white A4 paper. Check that the photo, QR code, and signature are sharp and readable.
  4. What if you lose your User ID or Password?
    // Recover User ID via SMS from Teletalk:
    BOGMC HELP USER <Name> <Father Name> → 16222
    // Recover Password via SMS:
    BOGMC HELP PIN <User ID> → 16222

💻 System B: BCC Direct e-Recruitment Portal

BCC (ICT Division)
  1. BCC Does NOT Use Teletalk:
    BCC operates its own internal applicant portal managed by the ICT Division at erecruitment.bcc.gov.bd.
  2. The SMS Alert:
    You will receive an official SMS from Sender ID: BCC or ICTD informing you of the written exam schedule and seat location.
  3. How to Download Admit Card:
    1. Visit erecruitment.bcc.gov.bd
    2. Log into your account using your Registered Email/Phone & Password.
    3. Go to "Applicant Dashboard" → "My Applications".
    4. Under your Assistant Programmer application, click the green "Download Admit Card" button.
  4. Where to Check Seat Plan & Exam Date Notice:
    Check the official notice board at bcc.gov.bd/notices. A detailed PDF listing roll numbers, exam hall names, and floor numbers is uploaded 3–5 days before the exam.
  5. Password Recovery:
    If you forget your BCC password, click "Forgot Password?" on the login screen to reset it via instant SMS OTP.

Technical Written Blueprint (CSE / IT Specific)

In BUET recruitment tests, CSE candidates get 5 pen-and-paper written technical questions. Here are the 5 exact high-probability problems with standard solutions:

Problem 1: Database Management Systems (SQL) 8 Marks

Question: Given an Employee (EmpID, EmpName, DeptID, Salary) and Department (DeptID, DeptName) table, write SQL queries to:

  1. Find the Department Name that pays the highest average employee salary.
  2. Find the 2nd highest salary from the Employee table without using the LIMIT or TOP keyword.
// Query 1 (Dept with highest avg salary):
SELECT d.DeptName, AVG(e.Salary) AS AvgSal
FROM Employee e JOIN Department d ON e.DeptID = d.DeptID
GROUP BY d.DeptName ORDER BY AvgSal DESC FETCH FIRST 1 ROW ONLY;
// Query 2 (2nd highest salary without LIMIT):
SELECT MAX(Salary) FROM Employee
WHERE Salary < (SELECT MAX(Salary) FROM Employee);
Problem 2: Computer Networks (IP Subnetting / VLSM) 8 Marks

Question: An ISP assigns Petrobangla the IP block 192.168.10.0/24. Divide this block into 4 equal subnets. For Subnet 1, determine: (a) Subnet Mask, (b) Network Address, (c) First Valid Host IP, (d) Last Valid Host IP, and (e) Broadcast Address.

Solution:
• To create 4 subnets: 2^n ≥ 4 ⇒ borrow 2 bits ⇒ New prefix = /26 (256 - 64 = 64 IPs per block)
• (a) Subnet Mask: 255.255.255.192
• (b) Network Address: 192.168.10.0
• (c) First Usable Host: 192.168.10.1
• (d) Last Usable Host: 192.168.10.62
• (e) Broadcast Address: 192.168.10.63
Problem 3: Operating Systems (CPU Scheduling & Deadlock) 8 Marks

Question: Consider processes P1 (Burst: 6ms), P2 (Burst: 4ms), P3 (Burst: 8ms) arriving at time t=0. Draw the Gantt chart and calculate Average Waiting Time (AWT) using Round Robin with Time Quantum Q = 2ms.

Gantt Chart: | P1(0-2) | P2(2-4) | P3(4-6) | P1(6-8) | P2(8-10) | P3(10-12) | P1(12-14) | P3(14-16) | P3(16-18) |
Completion Times: P1 = 14ms, P2 = 10ms, P3 = 18ms
Waiting Time: P1 = 14 - 6 = 8ms | P2 = 10 - 4 = 6ms | P3 = 18 - 8 = 10ms
Average Waiting Time (AWT) = (8 + 6 + 10) / 3 = 8.0 ms
Problem 4: Data Structures & Algorithms (Trees / Graphs) 8 Marks

Question: Insert keys [50, 30, 70, 20, 40, 60, 80] into an initially empty Binary Search Tree (BST). Give the In-order, Pre-order, and Post-order traversals.

• In-order (Sorted): 20, 30, 40, 50, 60, 70, 80
• Pre-order (Root-L-R): 50, 30, 20, 40, 70, 60, 80
• Post-order (L-R-Root): 20, 40, 30, 60, 80, 70, 50
Problem 5: Object-Oriented Programming (Design Principles) 8 Marks

Question: What is the difference between Function Overloading (Compile-time) and Function Overriding (Run-time)? Provide a brief C++ or Java demonstration showing Virtual Functions / @Override.

Exam Conductor Pattern: BUET vs. IBA

For technical jobs like Petrobangla AM (CSE/IT), Power companies (DESCO, DPDC, PGCB), recruitment exams are usually assigned to BUET or IBA.

BUET Pattern (Your Exam: Tech/Engineering)

Technical Heavy

BUET exams are typically **Written or MCQ + Written**. They emphasize core mathematical problem-solving in CSE subjects rather than generic trivia.

What they ask in Written:
  • SQL Queries: "Find the 2nd highest salary", "Retrieve employees working in more than 2 projects using JOIN".
  • Subnetting: Given an IP 192.168.10.0/26, calculate network address, broadcast address, and assign valid subnets for 3 departments.
  • Algorithms: Trace Dijkstra's shortest path on a given graph or trace QuickSort partition steps.
  • OS Scheduling: Calculate Average Waiting Time and Turnaround Time for Round Robin (Quantum=2) or SJF.
  • Code Output / Error tracing: Pointer tracing in C/C++ or Inheritance override in Java.

IBA Pattern (General Admin & Business)

Aptitude Heavy

For General Admin and Business posts, IBA conducts the exam with 70 MCQ + 30 Written (Focus writing, translation, math).

What they ask in IBA:
  • Advanced Math: Speed-Time-Distance with relative speeds, Permutations/Combinations, and Data Sufficiency questions.
  • Analytical Puzzles: Seating arrangement logic, condition-based ordering.
  • English: GRE-level sentence completion, Reading Comprehension with inferential questions, Error detection.
  • Written: 10 Marks Math + 10 Marks Focus Writing + 10 Marks Translation.
