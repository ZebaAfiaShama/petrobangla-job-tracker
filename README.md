## ⚡ Core Dashboard Modules & Features

### 1. 📅 30-Day Step-by-Step Daily Action Planner
* **3 Focused Daily Slots (~3 Hours Total):**
  - **Slot 1 (1.25 Hours):** Core Technical CSE (DBMS, Networks, OS, Data Structures, OOP).
  - **Slot 2 (45 Mins):** Real BUET Math (Formula-based short MCQs).
  - **Slot 3 (45 Mins):** English Grammar, Bangla Literature/Grammar, or Energy/Govt GK.
* **⚠️ Guilt-Free Catch-Up Queue (বকেয়া তালিকা):** If a candidate misses a day due to work or fatigue, clicking *"Mark Missed"* pushes the task into a persistent Catch-Up Queue for weekend completion without ruining the schedule.

### 2. 📐 Real BUET Math Blueprint (Zero Bank Arithmetic Word Problems)
* **What Was Eliminated:** 5-step lengthy commercial word problems (Cows/hens, Boat & Stream, Pipes & Cisterns, Vacation day equations).
* **What Is Tested (BUET Pattern):** 10 fast formula-based MCQs (15 Marks):
  1. **Logarithms (লগ):** $\log_2 4 + \log_2 8 - \log_4 16 = 3$, base conversion rules.
  2. **Indices (সূচক):** $5^{x+1} - 2\cdot 5^x = 3 \implies x = 0$.
  3. **Trigonometry:** $30^\circ, 45^\circ, 60^\circ$ right-angled triangle side ratio calculations.
  4. **Coordinate Geometry:** Distance formula $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$ & midpoint.
  5. **Circle Mensuration:** Arc length $s = r\theta$ ($\theta$ in radians) & sector area.
  6. **2D Mensuration:** Rectangle perimeter $2(L+W)$ where $L=3W$.
  7. **Vectors:** Vector dot product $\vec{A} \cdot \vec{B} = a_x b_x + a_y b_y + a_z b_z$ & angle $\cos\theta$.
  8. **Permutations & Combinations:** Committee formation $\binom{8}{4} = 70$.
  9. **Probability:** Sum of two dice $= 7$ ($P = 6/36 = 1/6$).
  10. **Calculus:** Definite area integration $\int_0^1 x^2 dx = 1/3$.

### 3. 📖 2024 BUET Question Bank (40 Solved MCQs)
* Interactive, filterable collection of all 40 questions from the 31 May 2024 BUET Petrobangla recruitment exam.
* One-click *"Show Answer &rarr;"* toggles detailed mathematical proofs and grammatical explanations.

### 4. ✍️ 40-Mark Technical Written Blueprint
Pen-and-paper solutions for the 5 high-probability BUET written problems:
1. **DBMS (SQL):** Multi-table JOINs, GROUP BY / HAVING, 2nd highest salary without `LIMIT`.
2. **Networking (VLSM Subnetting):** Subnet mask, valid host range, network and broadcast IP calculations for $/26$.
3. **Operating Systems:** Round Robin CPU scheduling Gantt chart (Quantum = 2ms) and Average Waiting Time (AWT).
4. **Data Structures:** Binary Search Tree (BST) key insertions and In-order, Pre-order, Post-order traversals.
5. **OOP:** Compile-time Overloading vs. Run-time Overriding (Virtual functions in C++ / Java `@Override`).

### 5. 🎯 3 Elite Jobs Hub & Admit Card Protocol
* **Admit Card Download Guides:** Complete walkthrough for Teletalk SMS alerts (Shortcode 16222) vs. BCC Direct e-Recruitment login.
* **SMS Recovery Protocols:** Fast commands to recover lost User IDs or PINs via SMS (`BOGMC HELP USER...`, `BCIC HELP USER...`).

* **Persistent Status Tracking:** Track each job from `Not Applied` &rarr; `Fee Paid` &rarr; `Admit Downloaded` &rarr; `Exam Attended`.

### 6. 🔄 Unified Syllabus Convergence Matrix
Demonstrates how **1 single preparation covers 85% of Petrobangla, BCC, and BCIC**, with only a 15% quick-win domain touchup (Energy Sector for Petrobangla, Cyber Law/ICT Act for BCC, Industrial IT for BCIC).

## 🛠️ Tech Stack & Architecture
* **Frontend:** Semantic HTML5, [Tailwind CSS CDN](https://tailwindcss.com), Vanilla JavaScript (ES6+).
* **State Management:** Browser `localStorage` (Preserves daily checklist, custom jobs, and status across page reloads with zero server overhead).
* **Hosting:** GitHub Pages (Automated static deployment on push to `main`).
* **Zero Dependencies:** Pure vanilla client-side application. No build step, node modules, or external databases needed.
