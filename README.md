# Petrobangla & Autonomous Job Preparation Dashboard 🎯

A modern, interactive Command Center and Study Hub built for **Petrobangla Assistant Manager (CSE / IT - 9th Grade)** and other Bangladesh Government / Autonomous recruitment examinations.

Live Demo: [https://zebaafiashama.github.io/petrobangla-job-tracker/](https://zebaafiashama.github.io/petrobangla-job-tracker/)

## Features
- **Official 2024 BUET Question Bank (40 Questions Solved):**
  - 10 Math & Quantitative Aptitude (with step-by-step proofs for logarithms, trigonometry, calculus, probability, vectors, and combinations).
  - 10 English Questions (grammar rules: subject-verb agreement, prepositions, gerunds, articles).
  - 10 General Knowledge & Hot Current Affairs (Raisi incident, NATO expansion, BRICS, Atanasoff digital computer).
  - 10 Bangla Questions (সমাস, কারক, উপসর্গ, পর্তুগীজ শব্দ).
- **Technical Written Blueprint (40 Marks):**
  - Pen-and-paper problems for SQL queries, IP Subnetting/VLSM, Round Robin CPU scheduling, Binary Search Trees, and OOP.
- **Application & Deadlines Tracker:**
  - Live countdown to application opening (19 Oct 2026) and closing (17 Nov 2026).
  - Teletalk SMS format cheat sheet and payment deadlines.
  - Vacancy breakdown across all 8 operating subsidiaries (TGTDCL, SGFL, GTCL, BGDCL, PGCL, BGFCL, BAPEX, JGTDSL).
- **Interactive Syllabus Checklist:**
  - Dynamic progress tracking saved to browser `localStorage`.
- **Zero Dependencies:**
  - Pure HTML5, Tailwind CSS, and vanilla JavaScript. Runs entirely client-side.
